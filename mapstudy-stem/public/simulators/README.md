# Nơi đặt mô phỏng HTML

Tạo thư mục cho từng chủ đề (ví dụ `con-lac-don/index.html`) và đặt HTML, CSS, JavaScript, hình ảnh đi kèm vào đây.

Cấu hình `embedSrc: '/simulators/con-lac-don/index.html'` trong `src/lib/simulations.ts`.

Chưa có mô phỏng thực tế trong phiên bản giao diện này. Các đối tượng đang dùng `embedSrc: null` để hiển thị vùng chờ.
